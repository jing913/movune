# Contributing

This is a public-source release-candidate branch, not the deployed Production branch.

- Do not commit credentials, local `.env` files, build output, source maps, coverage, or generated reports.
- Keep application changes separate from deployment/release changes.
- Do not describe source-only or in-development capabilities as Production-live.
- Use commit messages in the form `<type>: <English summary>（中文摘要）`.

The complete portfolio narrative, release policy, and contribution guide will be finalized in a later migration checkpoint.
